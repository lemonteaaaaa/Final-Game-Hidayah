# Folder Library

Letakkan **MySQL Connector/J** di folder ini dengan nama persis:

```
lib/mysql-connector-j.jar
```

Download dari: https://dev.mysql.com/downloads/connector/j/
(pilih "Platform Independent" → ambil file `.jar` di dalamnya, lalu rename
menjadi `mysql-connector-j.jar`).

JAR ini dibutuhkan untuk fitur **leaderboard / simpan skor** (koneksi ke MySQL).
Tanpa JAR ini game tetap bisa dimainkan, hanya fitur skor yang tidak aktif.
