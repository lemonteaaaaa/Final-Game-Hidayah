# Folder Audio

File audio (`.wav`) **tidak disertakan** di repository ini karena ukurannya besar
dan sebagian berhak cipta.

Game tetap bisa dijalankan tanpa file ini — hanya tidak ada suara/musik.

Jika ingin mengaktifkan suara, tambahkan file berikut ke folder ini
(gunakan audio milik sendiri atau yang bebas lisensi):

| Nama file      | Dipakai untuk        |
|----------------|----------------------|
| `Sumeru.wav`   | Musik latar          |
| `coin.wav`     | Efek: ambil item     |
| `powerup.wav`  | Efek: power up        |
| `unlock.wav`   | Efek: buka kunci     |
| `fanfare.wav`  | Efek: menang/selesai |
